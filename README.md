
# Team Version Control Project

## Objective
To implement collaborative version control using Git and GitHub.

## Modules
- Home Module: index.html
- Login Module: login.html
- Dashboard Module: dashboard.html

## Branching Strategy
Each team member develops an individual module in a separate branch.

## Workflow
1. Create a GitHub repository.
2. Create branches for individual modules.
3. Commit and push changes.
4. Create pull requests.
5. Review code before merging.
6. Resolve merge conflicts.
7. Merge approved changes into main.

## Tools
- Git
- GitHub
- Visual Studio Code
- HTML

## Result
The project demonstrates repository management,
branching, pull requests, code reviews, and conflict resolution.
